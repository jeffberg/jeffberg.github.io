The Diagnostic Engine

The name is borrowed from physics. In gauge theory, the central question is: what remains invariant under transformation? When you rotate a coordinate system, change your units, shift your frame of reference — what survives? GAUGE™ asks the same question of every dimensionality reduction ever published. When you project a thousand-dimensional manifold into two dimensions for a scatter plot, what survives — and what is quietly destroyed?

GAUGE™ is the diagnostic engine for PARALLAX™. It does not create embeddings. It does not optimize projections. It judges them. For every region of the projected space, it quantifies how much the embedding distorts the underlying manifold — how distances stretch or compress, how neighborhoods rearrange, how curvature appears where none existed, how information vanishes without a trace.

The field has built dozens of dimension reduction techniques — PCA, t-SNE, UMAP, diffusion maps, autoencoders, Isomap, locally linear embedding — and subjected them to exactly one diagnostic: “does the scatter plot look right?” This is the psychometric equivalent of validating a test by asking whether the scores feel reasonable. It is not science. It is aesthetics wearing a lab coat.

GAUGE fills the gap. Six diagnostics, each measuring a different face of the same distortion. Each implemented as a SQL query on real oceanographic data. Each revealing what the projection lost in order to show you what it shows you. The ocean is the test case. The framework is general.

Scenario I — Pairwise Distance Fidelity

When we project the ocean’s high-dimensional measurements into two dimensions, which pairs of points lose their true separation — and by how much?

-- GAUGE diagnostic: pairwise distance distortion -- compare Euclidean distances in original 4D feature space -- vs projected 2D space (lat, lon as proxy embedding) WITH feature_space AS ( SELECT profile_id, lat, lon, temperature_c, salinity_psu, oxygen_umol_kg, pressure_dbar FROM argo.float_profiles WHERE quality_flag IN (1, 2) AND temperature_c IS NOT NULL AND salinity_psu IS NOT NULL AND oxygen_umol_kg IS NOT NULL LIMIT 5000 ), distance_fidelity AS ( SELECT a.profile_id AS id_a, b.profile_id AS id_b, SQRT( POWER(a.temperature_c - b.temperature_c, 2) + POWER(a.salinity_psu - b.salinity_psu, 2) + POWER(a.oxygen_umol_kg - b.oxygen_umol_kg, 2) + POWER(a.pressure_dbar - b.pressure_dbar, 2) ) AS d_original, SQRT( POWER(a.lat - b.lat, 2) + POWER(a.lon - b.lon, 2) ) AS d_projected FROM feature_space a JOIN feature_space b ON a.profile_id < b.profile_id ), distortion_scored AS ( SELECT id_a, id_b, d_original, d_projected, d_projected / NULLIF(d_original, 0) AS distortion_ratio, ABS(d_projected - d_original) / NULLIF(d_original, 0) AS relative_error FROM distance_fidelity WHERE d_original > 0 ) SELECT ROUND(AVG(distortion_ratio)::numeric, 4) AS mean_distortion, ROUND(STDDEV(distortion_ratio)::numeric, 4) AS distortion_spread, ROUND(AVG(relative_error)::numeric, 4) AS mean_relative_error, COUNT(*) FILTER ( WHERE distortion_ratio > 2.0 OR distortion_ratio < 0.5 ) AS severely_distorted_pairs, COUNT(*) AS total_pairs, ROUND( 100.0 * COUNT(*) FILTER ( WHERE distortion_ratio > 2.0 OR distortion_ratio < 0.5 ) / COUNT(*)::numeric, 2 ) AS pct_severely_distorted FROM distortion_scored;
Distance is the most elementary geometric fact: how far apart are these two things? Every embedding implicitly answers this question for every pair of points. Most get it wrong. The distortion ratio reveals the lie: a ratio of 1.0 means the embedding preserved the true separation; anything else means it stretched or compressed reality. The percentage of severely distorted pairs is not a curiosity — it is the embedding’s error rate, stated honestly. A scatter plot that distorts 40% of its pairwise distances is not a visualization. It is a hallucination with axes.

Scenario II — Neighborhood Preservation

Does a point’s nearest neighbors in the full measurement space remain its neighbors after projection — or does the embedding silently rearrange what is close to what?

-- GAUGE diagnostic: k-nearest neighbor preservation -- Jaccard overlap between original and projected neighborhoods WITH profiles AS ( SELECT profile_id, lat, lon, temperature_c, salinity_psu, oxygen_umol_kg, pressure_dbar FROM argo.float_profiles WHERE quality_flag IN (1, 2) AND temperature_c IS NOT NULL AND salinity_psu IS NOT NULL AND oxygen_umol_kg IS NOT NULL LIMIT 2000 ), original_neighbors AS ( SELECT a.profile_id AS anchor_id, b.profile_id AS neighbor_id, RANK() OVER ( PARTITION BY a.profile_id ORDER BY SQRT( POWER(a.temperature_c - b.temperature_c, 2) + POWER(a.salinity_psu - b.salinity_psu, 2) + POWER(a.oxygen_umol_kg - b.oxygen_umol_kg, 2) + POWER(a.pressure_dbar - b.pressure_dbar, 2) ) ASC ) AS rank_original FROM profiles a JOIN profiles b ON a.profile_id <> b.profile_id ), projected_neighbors AS ( SELECT a.profile_id AS anchor_id, b.profile_id AS neighbor_id, RANK() OVER ( PARTITION BY a.profile_id ORDER BY SQRT( POWER(a.lat - b.lat, 2) + POWER(a.lon - b.lon, 2) ) ASC ) AS rank_projected FROM profiles a JOIN profiles b ON a.profile_id <> b.profile_id ), neighborhood_drift AS ( SELECT o.anchor_id, COUNT(*) FILTER ( WHERE o.rank_original <= 10 AND p.rank_projected <= 10 ) AS shared_neighbors, 10 AS k FROM original_neighbors o JOIN projected_neighbors p ON o.anchor_id = p.anchor_id AND o.neighbor_id = p.neighbor_id GROUP BY o.anchor_id ) SELECT ROUND(AVG(shared_neighbors / 10.0)::numeric, 4) AS mean_jaccard_overlap, ROUND(MIN(shared_neighbors / 10.0)::numeric, 4) AS worst_preservation, ROUND(STDDEV(shared_neighbors / 10.0)::numeric, 4) AS preservation_spread, COUNT(*) FILTER ( WHERE shared_neighbors < 3 ) AS catastrophic_rearrangements, COUNT(*) AS total_points FROM neighborhood_drift;
Distance fidelity asks about pairs. Neighborhood preservation asks about communities. A point’s ten nearest neighbors define its local context — what it is similar to, what it should be grouped with, what it can be interpolated from. When the embedding rearranges these neighborhoods, it does not just distort geometry. It breaks the inferential structure that every downstream analysis depends on. The Jaccard overlap is the embedding’s report card on local topology. Catastrophic rearrangements — points whose neighborhoods share fewer than three of ten members — are the places where the projection is not simplifying reality. It is inventing a new one.

Scenario III — Local Curvature Residuals

Where does the projected surface bend in ways the original manifold does not — and what does this phantom curvature reveal about the embedding’s assumptions?

-- GAUGE diagnostic: phantom curvature detection -- compare local variance structure at fine vs coarse scales -- to detect artificial smoothing or introduced wrinkles WITH fine_grain AS ( SELECT ROUND(lat::numeric, 0) AS lat_1deg, ROUND(lon::numeric, 0) AS lon_1deg, AVG(sst_c) AS mean_sst, STDDEV(sst_c) AS local_variance, STDDEV(sst_anomaly_c) AS anomaly_variance, COUNT(*) AS n_obs FROM noaa.sea_surface_temperature WHERE sst_c IS NOT NULL AND ice_concentration_pct < 15 GROUP BY lat_1deg, lon_1deg HAVING COUNT(*) >= 30 ), coarse_grain AS ( SELECT ROUND(lat_1deg / 5) * 5 AS lat_5deg, ROUND(lon_1deg / 5) * 5 AS lon_5deg, AVG(mean_sst) AS smooth_sst, AVG(local_variance) AS expected_variance, STDDEV(mean_sst) AS between_cell_variance, COUNT(*) AS n_cells FROM fine_grain GROUP BY lat_5deg, lon_5deg HAVING COUNT(*) >= 5 ), phantom_curvature AS ( SELECT f.lat_1deg, f.lon_1deg, f.mean_sst, c.smooth_sst, f.mean_sst - c.smooth_sst AS curvature_residual, ABS(f.mean_sst - c.smooth_sst) / NULLIF(c.expected_variance, 0) AS standardized_residual, f.local_variance, c.expected_variance, f.local_variance / NULLIF(c.expected_variance, 0) AS variance_ratio FROM fine_grain f JOIN coarse_grain c ON ROUND(f.lat_1deg / 5) * 5 = c.lat_5deg AND ROUND(f.lon_1deg / 5) * 5 = c.lon_5deg ) SELECT lat_1deg, lon_1deg, ROUND(curvature_residual::numeric, 3) AS residual_c, ROUND(standardized_residual::numeric, 3) AS z_residual, ROUND(variance_ratio::numeric, 3) AS var_ratio, CASE WHEN standardized_residual > 2.0 AND variance_ratio > 1.5 THEN 'phantom wrinkle' WHEN standardized_residual < 0.5 AND variance_ratio < 0.5 THEN 'artificial smoothing' ELSE 'faithful projection' END AS curvature_diagnosis FROM phantom_curvature WHERE standardized_residual > 2.0 OR variance_ratio NOT BETWEEN 0.5 AND 1.5 ORDER BY standardized_residual DESC LIMIT 30;
Curvature is the geometry’s second derivative — how the surface bends. When a projection introduces curvature that the original manifold does not possess, it creates phantom structure: wrinkles in the map that do not exist in the territory. Gulf Stream boundaries, equatorial upwelling zones, and polar transition regions are the usual suspects — places where the ocean’s true high-dimensional geometry is steep, and any flattening introduces artifacts. The variance ratio catches both failure modes: ratios above 1.5 indicate the projection has amplified local variation (wrinkles); ratios below 0.5 indicate it has suppressed it (smoothing). Both are lies. The question is whether anyone is checking.

Scenario IV — Instrument Agreement Under Projection

If two instruments converge in the original measurement space, do they still converge after projection — or does dimensionality reduction break the reliability that the raw data possessed?

-- GAUGE diagnostic: reliability preservation -- does instrument agreement survive projection? WITH co_located_raw AS ( SELECT b.station_id, f.float_id, b.sea_surface_temp_c AS buoy_sst, f.temperature_c AS float_sst, b.lat AS buoy_lat, b.lon AS buoy_lon, f.lat AS float_lat, f.lon AS float_lon, CASE WHEN b.lat BETWEEN -30 AND 30 THEN 'tropical' WHEN b.lat BETWEEN -60 AND -30 OR b.lat BETWEEN 30 AND 60 THEN 'temperate' ELSE 'polar' END AS climate_zone FROM noaa.buoy_observations b JOIN argo.float_profiles f ON ABS(b.lat - f.lat) < 0.5 AND ABS(b.lon - f.lon) < 0.5 AND ABS(EXTRACT(EPOCH FROM b.observation_ts - f.observation_ts)) < 3600 WHERE f.pressure_dbar < 10 AND f.quality_flag = 1 ), raw_reliability AS ( SELECT climate_zone, COUNT(*) AS n_pairs, CORR(buoy_sst, float_sst) AS raw_r, STDDEV(buoy_sst - float_sst) AS raw_disagreement FROM co_located_raw GROUP BY climate_zone ), projected_reliability AS ( SELECT climate_zone, CORR(buoy_lat, float_lat) AS proj_r_lat, CORR(buoy_lon, float_lon) AS proj_r_lon, STDDEV(buoy_lat - float_lat) AS proj_disagreement FROM co_located_raw GROUP BY climate_zone ) SELECT r.climate_zone, r.n_pairs, ROUND(r.raw_r::numeric, 4) AS raw_correlation, ROUND(r.raw_disagreement::numeric, 4) AS raw_noise, ROUND(p.proj_r_lat::numeric, 4) AS projected_r_lat, ROUND(p.proj_disagreement::numeric, 4) AS projected_noise, ROUND((r.raw_r - p.proj_r_lat)::numeric, 4) AS reliability_loss, CASE WHEN r.raw_r - p.proj_r_lat > 0.10 THEN 'projection degrades reliability' WHEN ABS(r.raw_r - p.proj_r_lat) <= 0.10 THEN 'reliability preserved' ELSE 'projection inflates agreement' END AS diagnostic FROM raw_reliability r JOIN projected_reliability p ON r.climate_zone = p.climate_zone ORDER BY reliability_loss DESC;
Reliability is the psychometrician’s first question: do repeated measurements agree? In the raw feature space, buoys and floats converge with high correlations — they are measuring the same ocean. But when we project those measurements into a reduced view, agreement can silently degrade. The reliability loss column is the smoking gun: it shows, per climate zone, how much inter-instrument convergence the projection destroyed. If polar regions show greater reliability loss than tropical ones, the embedding is not merely distorting geometry. It is introducing differential measurement error — making the instruments disagree about things they actually agreed on. This is not a visualization problem. It is a measurement integrity problem.

Scenario V — Information Loss by Region

Which ocean regions surrender the most information when compressed — and do the regions of greatest loss correspond to the regions of greatest scientific interest?

-- GAUGE diagnostic: regional information loss -- compare multivariate entropy in full space vs reduced view WITH ocean_basins AS ( SELECT profile_id, temperature_c, salinity_psu, oxygen_umol_kg, pressure_dbar, CASE WHEN lon BETWEEN -80 AND 0 THEN 'north_atlantic' WHEN lon BETWEEN -80 AND 0 AND lat < 0 THEN 'south_atlantic' WHEN lon BETWEEN 100 AND 180 OR lon BETWEEN -180 AND -80 THEN 'pacific' WHEN lon BETWEEN 30 AND 100 THEN 'indian' WHEN lat < -60 THEN 'southern' ELSE 'other' END AS basin FROM argo.float_profiles WHERE quality_flag IN (1, 2) AND temperature_c IS NOT NULL AND salinity_psu IS NOT NULL AND oxygen_umol_kg IS NOT NULL ), full_space_entropy AS ( SELECT basin, COUNT(*) AS n_profiles, STDDEV(temperature_c) AS sd_temp, STDDEV(salinity_psu) AS sd_sal, STDDEV(oxygen_umol_kg) AS sd_oxy, STDDEV(pressure_dbar) AS sd_pres, -- proxy for log-determinant of covariance LN(NULLIF(STDDEV(temperature_c), 0)) + LN(NULLIF(STDDEV(salinity_psu), 0)) + LN(NULLIF(STDDEV(oxygen_umol_kg), 0)) + LN(NULLIF(STDDEV(pressure_dbar), 0)) AS full_entropy_proxy FROM ocean_basins GROUP BY basin HAVING COUNT(*) >= 100 ), reduced_entropy AS ( SELECT basin, -- entropy in reduced 2D view (temp + salinity only) LN(NULLIF(STDDEV(temperature_c), 0)) + LN(NULLIF(STDDEV(salinity_psu), 0)) AS reduced_entropy_proxy FROM ocean_basins GROUP BY basin HAVING COUNT(*) >= 100 ) SELECT f.basin, f.n_profiles, ROUND(f.full_entropy_proxy::numeric, 3) AS entropy_full, ROUND(r.reduced_entropy_proxy::numeric, 3) AS entropy_reduced, ROUND((f.full_entropy_proxy - r.reduced_entropy_proxy)::numeric, 3) AS information_lost, ROUND(100.0 * (f.full_entropy_proxy - r.reduced_entropy_proxy) / NULLIF(f.full_entropy_proxy, 0)::numeric, 1) AS pct_information_lost, CASE WHEN (f.full_entropy_proxy - r.reduced_entropy_proxy) / NULLIF(f.full_entropy_proxy, 0) > 0.5 THEN 'critical loss' WHEN (f.full_entropy_proxy - r.reduced_entropy_proxy) / NULLIF(f.full_entropy_proxy, 0) > 0.25 THEN 'moderate loss' ELSE 'acceptable' END AS loss_severity FROM full_space_entropy f JOIN reduced_entropy r ON f.basin = r.basin ORDER BY information_lost DESC;
Information theory gives us what geometry alone cannot: a bookkeeping system for what was lost. The entropy proxy — the sum of log-standard-deviations across dimensions — captures the total variability in each basin’s multivariate signature. When we compress from four dimensions to two, the difference measures exactly how much structure we discarded. The pattern is rarely uniform. The Southern Ocean, with its violent mixing and extreme gradients in oxygen and pressure, typically surrenders the most — precisely because its high-dimensional structure is the richest. The tropics, more thermally monotone, lose less. This is the cruelest irony of dimensionality reduction: the regions that are most scientifically interesting are the regions most damaged by the tools we use to look at them.

Scenario VI — Cross-Scale Distortion Gradient

Does the distortion stay constant as we change resolution — or does the diagnostic itself depend on the scale at which we measure?

-- GAUGE diagnostic: scale-dependent distortion -- compute variance loss at 1°, 5°, and 10° resolutions WITH resolution_1deg AS ( SELECT ROUND(lat::numeric, 0) AS lat_bin, ROUND(lon::numeric, 0) AS lon_bin, 1 AS resolution_deg, AVG(sst_c) AS mean_sst, STDDEV(sst_c) AS within_cell_sd, AVG(sst_anomaly_c) AS mean_anomaly, STDDEV(sst_anomaly_c) AS anomaly_sd, COUNT(*) AS n_obs FROM noaa.sea_surface_temperature WHERE sst_c IS NOT NULL GROUP BY lat_bin, lon_bin HAVING COUNT(*) >= 10 ), resolution_5deg AS ( SELECT ROUND(lat::numeric / 5) * 5 AS lat_bin, ROUND(lon::numeric / 5) * 5 AS lon_bin, 5 AS resolution_deg, AVG(sst_c) AS mean_sst, STDDEV(sst_c) AS within_cell_sd, AVG(sst_anomaly_c) AS mean_anomaly, STDDEV(sst_anomaly_c) AS anomaly_sd, COUNT(*) AS n_obs FROM noaa.sea_surface_temperature WHERE sst_c IS NOT NULL GROUP BY lat_bin, lon_bin HAVING COUNT(*) >= 10 ), resolution_10deg AS ( SELECT ROUND(lat::numeric / 10) * 10 AS lat_bin, ROUND(lon::numeric / 10) * 10 AS lon_bin, 10 AS resolution_deg, AVG(sst_c) AS mean_sst, STDDEV(sst_c) AS within_cell_sd, AVG(sst_anomaly_c) AS mean_anomaly, STDDEV(sst_anomaly_c) AS anomaly_sd, COUNT(*) AS n_obs FROM noaa.sea_surface_temperature WHERE sst_c IS NOT NULL GROUP BY lat_bin, lon_bin HAVING COUNT(*) >= 10 ), all_scales AS ( SELECT * FROM resolution_1deg UNION SELECT * FROM resolution_5deg UNION SELECT * FROM resolution_10deg ) SELECT resolution_deg, COUNT(*) AS n_cells, ROUND(AVG(within_cell_sd)::numeric, 4) AS mean_within_sd, ROUND(STDDEV(mean_sst)::numeric, 4) AS between_cell_sd, ROUND(AVG(anomaly_sd)::numeric, 4) AS mean_anomaly_sd, ROUND( (AVG(within_cell_sd) / NULLIF(STDDEV(mean_sst), 0))::numeric, 4 ) AS distortion_index, CASE WHEN resolution_deg = 1 THEN 'fine — local fidelity' WHEN resolution_deg = 5 THEN 'medium — regional patterns' WHEN resolution_deg = 10 THEN 'coarse — basin-scale trends' END AS scale_interpretation FROM all_scales GROUP BY resolution_deg ORDER BY resolution_deg ASC;
The most uncomfortable finding in distortion analysis is this: the diagnosis depends on the doctor’s choice of magnifying glass. At one-degree resolution, the embedding looks faithful — local gradients are small, variance is well-captured. At ten-degree resolution, the same embedding may appear catastrophically lossy, because the between-cell structure it suppressed only becomes visible at larger scales. The distortion index — within-cell variance divided by between-cell variance — is the scale-dependent signature of projection quality. When it rises with resolution, the embedding is hiding large-scale patterns behind a mask of fine-grained noise. When it falls, the embedding is sacrificing local detail to preserve global shape. Neither is right. Both are measurable. And any diagnostic that reports a single distortion number without specifying its scale of measurement is not a diagnostic at all — it is an opinion.

Coda

Six diagnostics. One ocean. Each measuring a different face of the same distortion.

Pairwise distance fidelity asks whether the embedding preserves how far apart things truly are. Neighborhood preservation asks whether it keeps similar things together. Local curvature residuals ask whether it introduces structure that does not exist. Instrument agreement asks whether it breaks the reliability that the raw data possessed. Information loss asks which regions pay the highest tax. Cross-scale gradient asks whether the diagnosis itself is stable or a function of the observer’s chosen resolution.

GAUGE™ does not pick winners among embeddings. It maps their failures. It does not say which projection is best. It says, for any projection, precisely where and how it lies.

Paper 1 — The Parallax Imperative — demonstrated that every view of a complex system is partial. The temporal lens sees warming; the psychometric lens sees measurement noise; the network lens sees circulation topology. Each reveals what the others miss. GAUGE sees what each of those lenses lost in order to see what they see. It is the diagnostic of the diagnostics. The audit of the audit.

The field has spent five decades optimizing projections — minimizing stress functions, maximizing variance explained, preserving local neighborhoods at the expense of global structure or vice versa. It has spent almost no time measuring what those projections destroy. The optimization was always half the problem. The measurement was the other half, and it was left undone.

Every projection distorts. The question is where, and by how much.
